# Desktop App

## Features
- Archive Browser with incremental sync state per chat
- Import wizard for capture bundle JSON and official ChatGPT export ZIP
- Export jobs UI supporting incremental / force / repair modes
- Diagnostics screen with queued/failed/resumable/missing export counters
- Tauri command backend with SQLite persistence

## Run
```bash
pnpm --filter @project-archivist/desktop dev
```
